# SWYNEX – Final Data Analytics Project
## Indian Rainfall Analysis (1901–2017)

### 1. Project Overview
This project analyzes historical Indian rainfall data from 1901 to 2017. It combines data cleaning, exploratory data analysis (EDA), and an interactive Power BI dashboard to explore rainfall patterns across different subdivisions of India.

### 2. Problem Statement
Historical rainfall data can be difficult to interpret in its raw form. The goal of this project is to clean the dataset, identify important rainfall patterns, compare subdivisions, and present the findings through clear visualizations.

### 3. Dataset Information
- **Dataset:** Sub-Divisional Monthly Rainfall Data
- **Coverage:** 1901–2017
- **Geographical scope:** 36 subdivisions
- **Data fields:** Year, subdivision, monthly rainfall, annual rainfall, and seasonal rainfall.

### 4. Tools and Technologies
- Python
- Pandas
- Jupyter Notebook
- Microsoft Power BI
- GitHub

### 5. Data Cleaning Process
- Inspected the dataset structure and data types.
- Identified missing values and duplicate records.
- Removed 26 duplicate rows.
- Removed rows with missing values, resulting in 4,162 records.
- Checked annual and seasonal rainfall values for consistency.

### 6. Exploratory Data Analysis
The analysis explored:
- Average annual rainfall across subdivisions.
- Highest and lowest average rainfall subdivisions.
- Monthly rainfall patterns.
- Year-wise average annual rainfall trends.

### 7. Dashboard Highlights
The interactive Power BI dashboard includes:
- Total records and annual rainfall summary cards.
- Top 10 subdivisions by average annual rainfall.
- Bottom 10 subdivisions by average annual rainfall.
- Year-wise average annual rainfall trend.
- An interactive subdivision slicer.

### 8. Key Insights
- Arunachal Pradesh had the highest average annual rainfall among the subdivisions in this dataset.
- Coastal Karnataka also recorded a high average annual rainfall.
- Rainfall varies considerably across subdivisions.
- The dashboard makes it easier to compare subdivisions and explore rainfall trends over time.

### 9. Project Files
- `Weather_Data_Cleaning_EDA.ipynb` – Data cleaning and exploratory analysis.
- `cleaned_weather_data.csv` – Cleaned dataset.
- `SWYNEX_Indian_Rainfall_Dashboard.pbix` – Interactive Power BI dashboard.
- `dashboard_screenshot.png` – Dashboard preview.

### 10. Conclusion
This project provided practical experience in data cleaning, exploratory data analysis, data visualization, and dashboard development. It demonstrates an end-to-end approach to transforming raw rainfall data into meaningful insights.
